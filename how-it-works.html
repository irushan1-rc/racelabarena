02 Stage by stage

What each part does.

The experience depends on each layer doing one clear job inside the larger system.

01

Drive Input

Captures steering, throttle and braking from the simulator controls.

02

Race Console

Combines the driver interface, live view and session information.

03

Command Link

Carries intended control commands through the RLA system.

04

RLA Drive Module

Integrates onboard control functions with the physical vehicle.

05

Vehicle Link

Produces real steering, throttle and braking response on the RC vehicle.

06

Track System

Returns live FPV, telemetry and timing information to the driver.

03 Closed-loop driving

See. Input. Respond. Measure.

The loop never stops while you drive.

The live onboard view informs the driver's next input. The physical vehicle responds. Telemetry and timing reveal the result. The next correction follows.

This continuous loop is what makes RaceLab Arena a physical racing experience rather than a conventional racing game.
